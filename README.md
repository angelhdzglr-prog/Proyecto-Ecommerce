# 🛒 Emarket

Una aplicación de comercio electrónico desarrollada con React que simula una experiencia moderna de compra en línea utilizando la API DummyJSON.

## ✨ Demo

https://proyecto-ecommerce-peach.vercel.app/

## 📷 Capturas

(imágenes)

## 🚀 Características

- Catálogo de productos
- Búsqueda de productos
- Filtrado por:
  - categoría
  - precio
  - calificación
- Ordenamiento
- Carrito de compras
- Favoritos
- Productos vistos recientemente
- Compartir productos (Web Share API)
- Breadcrumb
- Skeleton Loading
- SEO básico
- Responsive Design
- Accesibilidad
- Animaciones

## 🛠 Tecnologías

- React
- Vite
- React Router
- React Query
- Axios
- TailwindCSS
- React Hot Toast
- React Helmet Async
- Context API
